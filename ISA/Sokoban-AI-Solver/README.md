# Sokoban AI Solver

Artificial Intelligence course project.

## Description
A Sokoban game implemented in Python using Tkinter with an automatic A* solver.

## Features
- Multiple Levels
- A* Search Algorithm
- Deadlock Detection
- Automatic Solver
- Timer and Move Counter

## Technologies
- Python
- Tkinter
- Pillow
